主进程

main.js · Node.js 唯一有权限碰窗口和文件的地方
1s计时循环 tick()
每 1000ms 一拍：getSystemIdleTime() ≤ 180s 才给今天 +1s；单次最多补 5 秒，防止睡眠后“补算”。
为什么：监听键鼠要全局钩子（要管理员权限、还会被杀软拦），系统空闲时间一行就够。
IO数据层 usage-store
按本地自然日累加，data/usage.json 每 20 秒落盘：先写 .tmp 再 rename，保留 120 天。
为什么：只存“每天累计多少秒”，不存原始事件，文件永远是几 KB。
UI窗口与层级
applyWindowLevel() 管三种状态：置顶 / 普通 / 固定桌面；固定时 setMovable(false) 锁死位置。
为什么：Electron 没有 moveBottom()，只能借 Win32 的 SetWindowPos 压到底层。
GL毛玻璃自愈
系统临时关掉透明效果会把亚克力变实心且不恢复：每 10 秒 setBackgroundMaterial() 重新贴一次。
为什么：这是 Windows 的行为，不是 bug；只能“重新贴材质”骗它重画。
WX天气
weather.js 拉 Open-Meteo，10 分钟缓存到 data/weather.json；城市查不到自动试英文名。
为什么：免费无 Key；城市库缺中文小城（“淮南”），加别名表回退。
OS托盘 / 菜单 / 快捷键
托盘常驻、右键菜单（外观 / 透明度 / 固定 / 穿透）、Ctrl+Alt+H / D / Q 全局快捷键。
为什么：桌面小组件要“常驻但安静”，关窗口不等于退出。

index.html
语义结构：标题 / 大数字 / 进度条 / 三格统计 / 7 日柱状图 / 天气块；CSP 只允许本地资源。
style.css
半透明卡片 + 内高光描边 + veil 三档透明度；acrylic 下显式关掉 backdrop-filter，避免把系统材质洗白。
app.js
只做“把数据写进 DOM”：更新数字、进度、柱高与天气；不做任何时间计算（避免两套逻辑打架）。
刷新策略
每分钟最多一次、只改变化的文本与柱高，7 根柱子只建一次。
整机 CPU ≈ 0.5% 单核。
